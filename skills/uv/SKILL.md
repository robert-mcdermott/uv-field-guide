# uv (Python package and project manager)

uv is a single Rust binary that replaces pyenv, venv/virtualenv, pip, pip-tools, pipx, Poetry-style project management and twine. This skill was verified against **uv 0.13.1** and **Ruff 0.17.0**. uv changes quickly, and several defaults changed in 2026, so **prefer this file over prior knowledge** where they disagree.

Human-readable companion: the uv Field Guide (`uv-guide.md` at the root of this repository).

## First, orient yourself

Run these before doing anything that changes the environment:

```bash
uv self version                     # behavior below assumes >= 0.13
ls pyproject.toml uv.lock .python-version requirements*.txt 2>/dev/null
grep -n "tool.uv\|build-system\|dependency-groups" pyproject.toml 2>/dev/null
```

Then pick the mode:

| What you find | Mode | Change dependencies with | Run code with |
|---|---|---|---|
| `pyproject.toml` (+ usually `uv.lock`) | **Project** | `uv add` / `uv remove` | `uv run …` |
| A single `.py` with a `# /// script` block | **Script** | `uv add --script file.py pkg` | `uv run file.py` |
| Only `requirements*.txt` (no pyproject) | **pip interface** | `uv pip install -r` / `uv pip compile` | activate `.venv` or `uv run --no-project` |
| A CLI tool is needed (ruff, httpie, pre-commit) | **Tool** | n/a | `uvx tool …` or `uv tool install tool` |

If a project has both `uv.lock` and `requirements.txt`, the lockfile is the source of truth and `requirements.txt` is usually generated by `uv export`. Don't hand-edit it; regenerate it.

## Facts that override older training data

- **`uv init` creates a packaged project by default (since 0.12):** `src/<name>/__init__.py`, a `[build-system]` using `uv_build`, and a `[project.scripts]` entry point. The old flat `main.py` layout now needs `uv init --no-package`.
- **Default downloaded Python is 3.15 (since 0.13).** Many packages lag new Pythons. Pin explicitly: `uv init -p 3.13`, `uv python pin 3.13`, or `uv venv -p 3.13`. Respect an existing `.python-version`.
- **`--native-tls` / `UV_NATIVE_TLS` were renamed** to `--system-certs` / `UV_SYSTEM_CERTS` (0.11). Use the new names for corporate TLS-inspecting proxies.
- **`uv venv` no longer overwrites** an existing environment without `--clear` (0.10), and needs `--force` to clear a non-venv directory (0.12).
- **Pre-releases:** uv tries stable versions first and falls back to pre-releases automatically (`--prerelease if-necessary`, 0.12).
- **`uv run path/to/script.py` discovers the project from the script's directory**, not the current directory (0.12). Override with `--project .`.
- **Preview commands** print an "experimental" warning: `uv format` (Ruff formatter, pinned to Ruff 0.15.x by default), `uv check` (ty type checker), `uv audit` (OSV vulnerability scan), `uv tool audit`, `uv cache size`, `uv workspace metadata`, `uv export --format cyclonedx1.5`. Silence with `--preview-features <name>` (e.g. `format-command`, `check-command`, `audit-command`) only if the user wants that.
- **There is no `uv lint`.** Lint with `uv run ruff check` (Ruff in the dev group) or `uvx ruff check`.
- **uv-created venvs contain no pip.** `python -m pip` fails. Use `uv pip …`, or `uv venv --seed` if a tool insists on pip.
- **`uv export -o file` also prints to stdout.** Redirect to `/dev/null` in scripts.

## Rules for agents

1. **Never hand-edit `uv.lock`.** Change `pyproject.toml` (or use `uv add`/`uv remove`) and let uv re-lock.
2. **In a project, never `uv pip install` or `pip install` into `.venv`.** The next `uv sync` removes anything not in the lockfile. For one-off needs use `uv run --with pkg …` or `uvx`.
3. **Use `uv run` rather than activating `.venv`** in automated steps. It locks and syncs first, so the environment is always correct.
4. **`uv sync` is exact.** It uninstalls packages that aren't in the selected groups. Before running a bare `uv sync`, check whether the user relies on non-default groups (`--group docs`, `--all-groups`, `--all-extras`) and pass them, or use `--inexact`.
5. **CI and reproducible builds:** `uv sync --locked` (fail if the lockfile is stale) or `uv lock --check`. Use `--frozen` only when you deliberately want to skip the check (e.g. a Docker layer that has only `uv.lock`).
6. **Don't upgrade dependencies unless asked.** `uv add`/`uv sync`/`uv run` keep locked versions. Upgrades are explicit: `uv lock --upgrade-package <pkg>` (or `--upgrade` for everything). Show the user the `uv.lock` diff.
7. **Respect the project's Python.** Don't pass `--python` that conflicts with `requires-python` or `.python-version` unless asked.
8. **Before publishing**, build with `uv build --no-sources` (catches reliance on `tool.uv.sources`) and smoke-test the wheel. Prefer TestPyPI first. Never print or commit tokens.
9. **Run tests and type checkers with `uv run`** (they must import the project). Use `uvx` only for tools that don't import project code.
10. If a command fails with a resolution error, read uv's explanation tree and fix the constraint; don't add `--prerelease allow` or overrides without telling the user.

## Everyday commands

```bash
# Python versions
uv python install 3.13            # also: list, find, pin, upgrade, uninstall, dir
uv python pin 3.13                # writes .python-version

# Projects
uv init my-app -p 3.13            # packaged app (default) | --lib | --no-package | --bare | --script x.py
uv add httpx "rich>=13"           # runtime deps
uv add --dev pytest ruff          # [dependency-groups] dev (installed by default)
uv add --group docs mkdocs        # other group (not installed by default)
uv add --optional plot matplotlib # extra
uv add -r requirements.txt [-c constraints.txt]
uv add git+https://github.com/org/repo --tag v1.2.3
uv add ../shared-lib --editable
uv remove httpx [--dev|--group g|--optional x]
uv run my-app | uv run pytest -q | uv run python -m module
uv run --with ipython ipython     # temporary extra package
uv lock [--check] [--upgrade] [--upgrade-package pkg]
uv sync [--locked] [--no-dev] [--all-groups] [--all-extras] [--inexact]
uv tree [--depth 1] [--outdated] [--invert --package pkg]
uv version [--bump major|minor|patch|beta|rc|stable] [--dry-run]

# Scripts (PEP 723)
uv init --script tool.py -p 3.13
uv add --script tool.py requests
uv run tool.py                    # isolated, cached env; ignores the surrounding project's deps
uv lock --script tool.py          # writes tool.py.lock
# shebang: #!/usr/bin/env -S uv run --script

# Tools
uvx ruff check                    # = uv tool run; ruff@0.17.0 or ruff@latest for versions
uvx --from httpie http --version  # package name differs from command
uv tool install httpie | uv tool list | uv tool upgrade --all | uv tool uninstall httpie

# Quality
uv run ruff check --fix && uv run ruff format
uv format [--check|--diff]        # preview
uv check                          # preview: ty type checker
uv audit                          # preview: vulnerabilities in uv.lock

# pip interop
uv export --no-dev --no-hashes --no-emit-project -o requirements.txt
uv venv -p 3.13 && uv pip install -r requirements.txt
uv pip compile requirements.in -o requirements.txt --universal
uv pip sync requirements.txt

# Build and publish
uv build [--no-sources] [--clear]
uv publish [--index testpypi] [--dry-run]   # token via UV_PUBLISH_TOKEN, or trusted publishing in CI
```

## Files

| File | Commit? | Notes |
|---|---|---|
| `pyproject.toml` | yes | Intent: metadata, dependency ranges, `[dependency-groups]`, `[tool.uv]`, `[tool.ruff]` |
| `uv.lock` | yes | Universal lockfile (all platforms/Pythons). Managed by uv only. |
| `.python-version` | yes | Default interpreter for the project |
| `.venv/` | no | Disposable; recreate with `uv sync` |

Dependency kinds: `[project].dependencies` (published), `[project.optional-dependencies]` (extras, published, opt-in), `[dependency-groups]` (local only; `dev` is installed by default; change with `[tool.uv] default-groups`). Non-registry sources live in `[tool.uv.sources]` and are ignored by tools other than uv.

## Troubleshooting quick map

| Symptom | Fix |
|---|---|
| Package vanished after `uv sync` | Exact sync; add it with `uv add`, include its group, or use `--inexact` |
| `VIRTUAL_ENV … does not match the project environment` | Another venv is active; `deactivate`, or pass `--active` deliberately |
| Certificate verify failed | `--system-certs` / `UV_SYSTEM_CERTS=1`, or `SSL_CERT_FILE=/path/ca.pem` |
| `Failed to hardlink files` warning | Different filesystems; `UV_LINK_MODE=copy` |
| `uvx tool` is stale | `uvx tool@latest` or `--refresh` |
| "self-dependencies are not permitted" | Don't `uv add` the project itself; use `--dev`/`--optional`, or rename the project |
| Stale cache / odd build | `uv cache clean <pkg>` or `uv sync --refresh-package <pkg> --reinstall-package <pkg>` |
| Need more detail | `-v` / `-vv`, or `uv help <command>` |
