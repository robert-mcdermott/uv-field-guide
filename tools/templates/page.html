The uv Field Guide

Everything a Python team needs to move onto uv: installing Python, starting projects, managing dependencies, running scripts and tools, staying compatible with plain pip, and publishing to PyPI. Includes a little Ruff. Every example was run on the versions in the header.

Using an AI coding agent? Give it the companion uv agent skill so it follows the same current rules. In Claude Code: /plugin install uv --marketplace robert-mcdermott/uv-field-guide
